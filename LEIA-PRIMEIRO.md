## 🚀 3 PASSOS (15 minutos):

### **PASSO 1️⃣ - Firebase (5 min)**

1. Abra: `firebase.google.com`
2. Clique: **"Começar"**
3. Crie projeto: `Santo Barbearia`
4. Vá em: **"Realtime Database"**
5. Clique: **"Criar banco de dados"**
6. Escolha: **"Modo de teste"**
7. Pronto!

**Agora copie essas 7 coisas:**
- apiKey
- authDomain
- databaseURL
- projectId
- storageBucket
- messagingSenderId
- appId

💡 **Dica:** Clique em "Configurações do projeto" (engrenagem) → "Geral" → Copia `firebaseConfig`

---

### **PASSO 2️⃣ - GitHub (3 min)**

1. Abra: `github.com`
2. Faça login (ou cria conta)
3. Clique: **"New repository"**
4. Nome: `santo-barbearia-app`
5. Clique: **"Create repository"**
6. Copie o código de upload que aparece

**No seu PC:**
- Abre terminal/CMD
- Copia e cola o comando de upload
- Sobe seus arquivos pra GitHub

---

### **PASSO 3️⃣ - Vercel (2 min)**

1. Abra: `vercel.com`
2. Login com GitHub
3. Clique: **"New Project"**
4. Selecione: `santo-barbearia-app`
5. Clique: **"Import"**
6. **Environment Variables** - Adicione as 7 chaves do Firebase:
   ```
   VITE_FIREBASE_API_KEY = [copie aqui]
   VITE_FIREBASE_AUTH_DOMAIN = [copie aqui]
   [etc...]
   ```
7. Clique: **"Deploy"**
8. **PRONTO!** ✨ Seu app fica online em ~2 min!
